.badge 徽章组件

HTML / CSS 使用文档 — 四种语义变体 + 数字角标

1. 四种变体定义

.badge 是基础类，提供内联块级布局、内边距和圆角。 通过追加语义变体类名来设定背景色与文字色。

变体 类名 背景色 文字色 圆角
Primary .badge-primary #0d6efd #ffffff 12px
Success .badge-success #198754 #ffffff 12px
Warning .badge-warning #ffc107 #212529 12px
Danger .badge-danger #dc3545 #ffffff 12px
Primary Success Warning Danger 
<!-- 基础用法 -->
<span class="badge badge-primary">Primary</span>
<span class="badge badge-success">Success</span>
<span class="badge badge-warning">Warning</span>
<span class="badge badge-danger">Danger</span>

2. 核心 CSS 代码

/* 基础样式 */
.badge {
  display: inline-block;
  padding: 4px 12px;
  font-size: 13px;
  font-weight: 600;
  line-height: 1.4;
  text-align: center;
  white-space: nowrap;
  vertical-align: middle;
  border-radius: 12px;
}

/* Primary — 蓝色 */
.badge-primary {
  background-color: #0d6efd;
  color: #ffffff;
}

/* Success — 绿色 */
.badge-success {
  background-color: #198754;
  color: #ffffff;
}

/* Warning — 黄色（深色文字以保证可读性） */
.badge-warning {
  background-color: #ffc107;
  color: #212529;
}

/* Danger — 红色 */
.badge-danger {
  background-color: #dc3545;
  color: #ffffff;
}

/* 数字角标 */
.badge-count {
  min-width: 20px;
  padding: 2px 6px;
  border-radius: 50%;
  font-size: 12px;
}

3. 数字角标 .badge-count

.badge-count 用于在图标或按钮右上角显示未读数量。 它与 .badge-wrapper 定位容器配合使用，通过绝对定位将角标固定在右上角。 border-radius: 50% 使其呈现圆形外观。

🔔 3 ✉ 12 🛒 5 💬 99+ 
<!-- HTML: 数字角标用法 -->
<span class="badge-wrapper">
  <span class="icon-placeholder">&#128276;</span>
  <span class="badge badge-count badge-danger">3</span>
</span>

<span class="badge-wrapper">
  <span class="icon-placeholder">&#9993;</span>
  <span class="badge badge-count badge-primary">12</span>
</span>

<span class="badge-wrapper">
  <span class="icon-placeholder">&#128722;</span>
  <span class="badge badge-count badge-success">5</span>
</span>

<span class="badge-wrapper">
  <span class="icon-placeholder">&#128172;</span>
  <span class="badge badge-count badge-warning">99+</span>
</span>
/* 角标定位容器 */
.badge-wrapper {
  position: relative;
  display: inline-block;
}

.badge-wrapper .badge-count {
  position: absolute;
  top: -8px;
  right: -8px;
}

4. 使用指南

基础徽章：始终同时添加 .badge 基础类和一个变体类（如 .badge-primary）。

数字角标：在 .badge 基础上追加 .badge-count 类，并将整个组合放入 .badge-wrapper 容器中以实现右上角定位。

无障碍：当角标仅含数字、无可见文本时，建议添加 aria-label 属性，例如 aria-label="3 条未读消息"。

<!-- 无障碍示例 -->
<span class="badge-wrapper">
  <button aria-label="通知">🔔</button>
  <span class="badge badge-count badge-danger" aria-label="3 条未读通知">3</span>
</span>
