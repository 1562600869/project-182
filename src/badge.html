.badge 徽章组件

HTML / CSS 使用文档 — 四种变体 + 数字角标

1. 概览

.badge 是一个轻量级的行内徽章组件，适用于状态标签、分类标记等场景。 组件提供四种语义变体：Primary、Success、Warning、Danger， 并支持通过 .badge-count 在任意元素右上角添加数字角标。

Primary Success Warning Danger

2. 变体定义

变体 CSS 类名 背景色 文字颜色 圆角 预览
Primary .badge-primary #1677ff #ffffff 10px 标签
Success .badge-success #52c41a #ffffff 10px 已通过
Warning .badge-warning #faad14 #ffffff 10px 待审核
Danger .badge-danger #ff4d4f #ffffff 10px 异常

3. 基础用法

为 <span> 添加 .badge 基础类和对应的变体类即可：

<span class="badge badge-primary">Primary</span>
<span class="badge badge-success">Success</span>
<span class="badge badge-warning">Warning</span>
<span class="badge badge-danger">Danger</span>

渲染结果

Primary Success Warning Danger

4. CSS 定义参考

/* 基础样式 */
.badge {
  display: inline-block;
  padding: 4px 10px;
  font-size: 12px;
  font-weight: 600;
  line-height: 1;
  text-align: center;
  white-space: nowrap;
  vertical-align: middle;
  border-radius: 10px;
  color: #ffffff;
}

/* Primary — 背景: #1677ff, 文字: #ffffff, 圆角: 10px */
.badge-primary {
  background-color: #1677ff;
}

/* Success — 背景: #52c41a, 文字: #ffffff, 圆角: 10px */
.badge-success {
  background-color: #52c41a;
}

/* Warning — 背景: #faad14, 文字: #ffffff, 圆角: 10px */
.badge-warning {
  background-color: #faad14;
}

/* Danger — 背景: #ff4d4f, 文字: #ffffff, 圆角: 10px */
.badge-danger {
  background-color: #ff4d4f;
}

5. 数字角标（.badge-count）

使用 .badge-wrapper 包裹目标元素，在其内部添加 .badge-count 即可在右上角显示数字角标。

HTML 结构

<div class="badge-wrapper">
  <span class="icon-box">🔔</span>
  <span class="badge-count">5</span>
</div>

<div class="badge-wrapper">
  <span class="icon-box">✉</span>
  <span class="badge-count">99+</span>
</div>

渲染结果

🔔 5
✉ 99+

CSS 定义

.badge-wrapper {
  position: relative;
  display: inline-block;
}

.badge-count {
  position: absolute;
  top: -8px;
  right: -8px;
  min-width: 18px;
  height: 18px;
  padding: 0 5px;
  font-size: 12px;
  font-weight: 600;
  line-height: 18px;
  text-align: center;
  white-space: nowrap;
  color: #ffffff;
  background-color: #ff4d4f;
  border-radius: 9px;
  box-shadow: 0 0 0 2px #ffffff;
}
